# LexiSnake V2 — Neon Web Game

[เล่นออนไลน์](https://lexisnake.vercel.app) · [GitHub Actions](https://github.com/BeelzebubCode/snake-game/actions/workflows/web-ci.yml)

เกมเว็บ React + TypeScript + Phaser + Vite ที่เล่นได้จริง พัฒนาแยกจาก Python ในโฟลเดอร์ Web/

## เปิดเล่นในเครื่อง

ต้องมี Node.js 22.12 ขึ้นไป (ทดสอบด้วย 22.21.1)

จาก root ของ repository:

```bash
cd Web
npm ci
npm run dev
```

เปิด URL ที่ Vite แสดง ปกติเป็น http://127.0.0.1:5173/

## สิ่งที่ทำแล้ว

- Home พื้นเข้ม สีสดจาก Python พร้อมภาพตัวงูและคำอธิบายกล่องสมบัติ
- บทฝึกหยุดให้ทบทวนและกดไปต่อเอง หลังเก็บอักษร/รับกล่องจะไฮไลต์กระเป๋าจริงใต้สนาม กล่องฝึกรอให้กดเริ่มเปิดก่อน
- กดเล่นแล้วเลือกมือใหม่/ผู้เล่นเก่า มือใหม่เข้าบทสอน 7 ขั้นพร้อมภาพ: เลี้ยวครบ 4 ทิศ → Shift เร่ง → เก็บ C → เปิดกล่องรับ A/T → เข้าประตู → เรียง CAT → กติกาพัก/หัวใจ
- สนามกว้าง 40 × 22 ช่อง ใช้พื้นที่หลักของหน้าเล่น กระเป๋าอักษรอยู่ด้านล่าง รองรับเต็มจอและปุ่มสัมผัส
- ความเร็วเริ่มต้น **ช้า** (5 ช่อง/วินาที) เลือกปกติ 8 / เร็ว 12 / เร็วมาก 16 ได้
- สกินสีเดิม 4 ชุด: Neon Mint / Cyber Purple / Golden Fire / Ocean Blue เลือกตัวงูเรียบหรือคลาสสิก และเปิด/ปิดเส้นตาราง
- แมพ 4 แบบ เปลี่ยนทุก 1,500 คะแนนในรอบ หรือเลือกแมพคงที่ได้ในตั้งค่า
- การเคลื่อนที่ต่อเนื่องทั้งแนวนอน/ตั้ง เก็บมุมเลี้ยวตามสนาม และหมุนหัวตามทิศ
- ลูกศรด้านหน้าหัวงูและแถบนับถอยหลัง บอกทิศที่เกมยอมรับก่อนเดินต่อ รวมถึงตอนออกประตู
- หัวใจ 3 ดวง: เมื่อตายตอบคำศัพท์จากคำแปลไทยให้ถูกภายใน 30 วินาที ใช้ 1 หัวใจ หัก 100 คะแนน ต่ำสุด 0
- ตอบฟื้นคืนชีพผิดลองใหม่ได้ในเวลาที่เหลือ ฟื้นได้สูงสุด 3 ครั้งต่อรอบ
- เวลาเรียงคำในประตูเริ่มต้น **60 วินาที** ตั้งได้ 15 / 30 / 45 / 60 / 90 / 120 วินาที
- ตัวอักษรบนสนาม 3 ตัว แต่ละตัวอยู่ได้ 30 วินาทีของเวลาเล่นจริง และเติมกลับให้ครบ
- กล่องเงิน / ทอง / ม่วง / แดง ให้ 2 / 3 / 4 / 5 ตัวอักษร มีภาพสุ่มและเปิดรางวัล
- หยุดเวลาโลกขณะเปิดกล่อง เรียงคำ ฟื้นคืนชีพ พัก และซ่อนแท็บ
- เสียงเอฟเฟกต์สังเคราะห์ เสียงอ่านผ่านระบบของเบราว์เซอร์ และโหมดลดการเคลื่อนไหว
- Popup ตั้งค่าแบ่ง sidebar 4 หมวด: การเล่น / ตัวงู / แมพและสนาม / เสียงและเอฟเฟกต์ พร้อมปุ่มบันทึกที่เห็นตลอด
- บันทึก settings คะแนนสูงสุด และสมุดคำศัพท์ใน localStorage
- โหลดคลังเดิม 32,991 คำ และมีชุดพื้นฐานสำรองเมื่อโหลดคลังหลักไม่ได้

อ่านกติกาที่ตัดสินใจร่วมกันใน [V2_SPEC.md](V2_SPEC.md)

## Build และตรวจสอบ

```bash
npm test
npm run build
npm run preview
npm run test:e2e
npm run format:check
```

ผล build อยู่ใน dist/ และไม่ต้องใช้ Python หรือ server API ระหว่างเล่น

Browser tests ใช้ Chrome ที่ติดตั้งในเครื่อง ถ้าใช้ CI ให้ติดตั้ง Chromium ของ Playwright ด้วยคำสั่ง npx playwright install --with-deps chromium แล้วรันโดยกำหนด CI=true

มี unit tests 38 ข้อสำหรับกติกา/เซฟ/การเคลื่อนที่/แมพ และ browser tests 9 เส้นทาง: Home/settings, tutorial ครบ 7 ขั้น, ปุ่มควบคุมบทสอนบนมือถือ, mobile layout, revival, เดินไปเปิดกล่องเงินจริง, เซฟรูปลักษณ์ เปลี่ยนแมพพร้อมลูกศรหลังออกประตู และ sidebar ตั้งค่าบนมือถือ ชุดทดสอบกำหนด RNG ของเกมผ่าน network fixture โดยไม่เพิ่ม debug controls ลงใน production

ตรวจภาพ Home บน desktop/mobile และสนาม desktop ด้วย Chrome แล้ว ยังไม่ได้ทดสอบ Safari หรือการสัมผัสบนอุปกรณ์จริง เสียงอ่านขึ้นกับเสียงที่เบราว์เซอร์/ระบบปฏิบัติการมี

## คลังศัพท์และ assets

- สร้างข้อมูลเว็บซ้ำจากไฟล์ V1 ด้วย npm run data:build
- ข้อมูลที่สร้างแล้วอยู่ใน public/data/vocabulary.json จึง build เว็บได้โดยไม่เรียก Python
- ระดับและคำแปลจากคลังเดิมบางส่วนยังต้องตรวจทาน ดู public/data/README.md
- คำฟื้นคืนชีพใช้รายการคำแปลสั้นที่เลือกไว้ใน src/data/vocabulary.ts
- ฟอนต์และใบอนุญาตอยู่ใน public/fonts/
- ภาพสวน กล่อง และงูเป็น SVG/กราฟิกในโค้ด เสียงเอฟเฟกต์สร้างด้วย Web Audio
