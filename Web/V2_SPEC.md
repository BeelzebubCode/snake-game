# V2 — ข้อกำหนดที่ใช้ในเกมเว็บ

เอกสารนี้เป็นกติกาปัจจุบัน และใช้แทนข้อเสนอที่ขัดกันใน V2_PLAN.md

## หน้า Home และการเริ่มรอบ

Home พื้นเข้มใช้สีสดจาก Python มีพื้นที่หลักเป็นภาพสวนและปุ่มเข้าไปเล่นกัน เมนูสมุดศัพท์/ตั้งค่าอยู่หน้า Home ส่วนหน้าเล่นใช้สนามกว้าง 40 × 22 ช่อง พร้อมแถบคะแนน หัวใจ ปุ่มพัก และกระเป๋าอักษรด้านล่าง

ทุกครั้งที่กดเล่นจาก Home ให้เลือก:

- มือใหม่ → บทสอนแบบเล่นจริง 8 ขั้น: เลี้ยวครบ 4 ทิศ → Shift เร่ง → เก็บ C → เปิดกล่องเงินรับ A/T → เข้าประตู → เรียง CAT → ชนอิฐแดง → สรุปกติกา (หัวใจ ฟื้นคืนชีพ เพดานกระเป๋า ประตูบังคับ)
- ผู้เล่นเก่า → นับถอยหลัง 3 วินาทีแล้วเริ่มรอบ

รอบปกติเริ่มด้วยหัวใจ 3 ดวง คะแนน 0 และอักษร CAT ในกระเป๋าเพื่อให้ทดลองเรียงคำแรกได้ ความเร็วเริ่มต้นช้า 6 ช่อง/วินาที; ปกติ 8 เร็ว 12 และเร็วมาก 16 ช่อง/วินาที กดเร่งได้ 1.7 เท่า

## ภาษา

- ค่าเริ่มต้น English; เลือก English / ไทย (Thai) ใน Settings → Gameplay → Language
- Popup ตั้งค่า preview ภาษาที่เลือกทันที Apply Settings จึงบันทึกใช้ทั้งเกม ปิด/ยกเลิกแล้วคงภาษาเดิม
- เมนู ข้อความเกม บทสอน ภาพประกอบ ป้ายสนาม และข้อความอ่านหน้าจอใช้คำแปลกลางชุดเดียวกัน
- เซฟ V2 เก่าที่ยังไม่มี language จะใช้ English พร้อมรักษาคะแนนและคำศัพท์เดิม
- คลังคำอังกฤษ คำแปลไทย และโจทย์ฟื้นคืนชีพเป็นเนื้อหาการเรียนแยกจากภาษา UI
- พิมพ์/วางอักษรเกินที่มีแล้วแจ้งอักษรที่ขาดใต้ช่องพิมพ์ โดยไม่เปลี่ยนคำที่พิมพ์ไว้ กระเป๋าว่างจะแสดงข้อความให้เก็บอักษรก่อน

## รูปลักษณ์ แมพ และการเลี้ยว

- สีงูอ้างอิง SKINS ใน src/ui.py ที่ tag python-v1-archive: Neon Mint (เขียว→ฟ้า), Cyber Purple (ชมพู→ม่วง), Golden Fire (เหลือง→แดง), Ocean Blue (ฟ้า→น้ำเงิน)
- รูปแบบเริ่มต้นเป็นตัวเรียบไล่สี ไม่มีจุดบนลำตัว; เลือกคลาสสิกเป็นข้อมนได้
- งูเคลื่อนที่แบบแทรกตำแหน่งระหว่าง tick ทั้งสองแกน ลำตัวต่อเนื่องผ่านมุมจริง และหัวหมุนตามทิศอย่างค่อยเป็นค่อยไป
- เปิด/ปิดเส้นตารางได้
- แมพอัตโนมัติเปลี่ยนตามคะแนนในรอบ: 0 Neon Grid → 1,500 Firefly Forest → 3,000 Midnight Ocean → 4,500 Ember Valley → 6,000 กลับ Neon Grid แล้ววนต่อทุก 1,500 คะแนน
- ใช้ระดับแมพสูงสุดที่ถึงแล้วในรอบ การหักคะแนนฟื้นคืนชีพไม่ทำให้แมพย้อนกลับ รอบใหม่เริ่มจากแมพแรก
- เลือกแมพคงที่ทั้งรอบได้ แมพเป็นฉากเท่านั้น ไม่เพิ่มสิ่งกีดขวางหรือรีเซ็ตงู/ตัวอักษร
- เปลี่ยนแมพด้วยการค่อย ๆ เปลี่ยนภาพ 700 มิลลิวินาที โหมดลดการเคลื่อนไหวเปลี่ยนทันที
- ลูกศรด้านหน้าหัวงูและแถบนับถอยหลังแสดงทิศถัดไป รวมทั้งหลังออกประตู กดลูกศร/WASD เปลี่ยนได้จนเริ่มเดิน
- ลูกศรเว้นระยะให้เห็นหัวงูชัด ถ้าอยู่ชิดขอบจะขยับเฉียงข้างเพื่อไม่ย้อนมาทับใบหน้า
- ตั้งค่าเป็น popup มี sidebar 4 หมวด เก็บค่าที่แก้ระหว่างสลับหมวดจนกดบันทึก กดยกเลิก/ปิดแล้วไม่เปลี่ยนเซฟ
- ขณะนับถอยหลังเก็บเฉพาะทิศล่าสุดที่ปลอดภัย โดยห้ามกลับหลังเทียบกับทิศจริงก่อนหยุด
- ตัวเลือกชุดคำศัพท์มีทุกระดับ, ง่าย A1–A2, ปานกลาง B1–B2, ยาก C1–C2 และเลือกแต่ละระดับได้
- ตั้งค่าใหม่เติมค่าเริ่มต้นให้เซฟ V2 เดิม โดยรักษาคะแนน สถิติ และสมุดคำศัพท์

## โหมดฝึกสอนแบบมีผู้แนะนำ

- แต่ละบทมี popup พร้อมภาพและคำอธิบาย เกมหยุดรอให้อ่าน กดปุ่ม/Enter หรือ × เพื่อเริ่มลงมือทำ
- บทเลี้ยวใช้ความเร็วช้า 6 ช่อง/วินาทีเท่ากับรอบจริงและค่า Python ฝึกขึ้น → ซ้าย → ลง → ขวา อย่างละ 3 ช่อง มีรายการบอกทิศที่ผ่านแล้ว บทเร่งกด Shift/Space หรือปุ่มเร่งบนจอจนเดินแบบเร่งครบ 5 ช่อง
- หลังฝึกเลี้ยว เร่ง เก็บ C และรับรางวัลกล่อง จะหยุดในขั้นทบทวน ไม่เปลี่ยนบทจนกดปุ่มไปต่อ
- อักษรและกล่องฝึกอยู่ห่างจุดเริ่ม 10 ช่อง หลังเก็บจะเน้นอักษรใหม่และกรอบกระเป๋าใต้สนาม กระพริบช้า 3 รอบและคงกรอบไว้ ปิดกระพริบเมื่อเปิดลดการเคลื่อนไหว
- เก็บกล่องแล้วรอให้กดเริ่มเปิด เมื่อเห็น A/T ต้องกดรับเข้ากระเป๋า แล้วดูผลในกระเป๋าจริงก่อนกดไปบทประตู
- บทเก็บอักษรมี C ตัวเดียว กล่องฝึกเป็นกล่องเงินที่กำหนด A/T ไว้ให้เรียนต่อ โดยอธิบายรางวัลจริง เงิน 2 / ทอง 3 / ม่วง 4 / แดง 5
- บทประตูมีเพียงประตูสีเขียว ไม่ใช้ตัวเติมอักษร 3 ตัว กล่องสุ่ม หรือเวลาสุ่มประตูของรอบปกติ
- วัตถุฝึกไม่หมดอายุระหว่างฝึก ชนแล้วเปิดคำอธิบายบทเดิมและจัดสนามใหม่ เก็บ inventory และหัวใจไว้
- ก่อนเรียงคำมี popup อธิบาย CAT, Enter, Backspace, ช่วยเรียง และเวลา แสดงโจทย์ CAT ตลอดบท
- ใช้ความเร็วช้าและเวลาเรียงคำ 60 วินาทีเฉพาะรอบฝึก ไม่เปลี่ยนค่าที่บันทึกไว้ หมดเวลาเริ่มโจทย์ใหม่ได้
- มีแถบเป้าหมายบนสนามและปุ่มดูคำอธิบายซ้ำ กลับจากคำอธิบายยังใช้ตัวอักษร คำที่พิมพ์ และเวลาโจทย์เดิม
- สรุปการพักเกม การใช้หัวใจและหักคะแนนก่อนจบบทเรียน บทสอนไม่เพิ่มคะแนนสูงสุดหรือจำนวนรอบปกติ

## ตัวอักษรบนสนาม

ตามคำตอบของผู้ใช้: มีตัวอักษรเดี่ยว 3 ตัว ไม่ใช่ 3 คำหรือ 3 กล่อง

- แต่ละตัวมีอายุ 30 วินาทีแยกกัน
- เมื่อเก็บหรือหมดอายุ เติมตัวใหม่ในช่องว่างให้ครบ 3
- ไม่เกิดทับงู ตัวอักษร กล่อง หรือพื้นที่ประตู
- เก็บหนึ่งตัวเพิ่ม inventory และหางหนึ่งข้อ
- เวลา 30 วินาทีเดินเฉพาะตอนควบคุมงู; หยุดระหว่างเมนู/เหตุการณ์ที่พักโลก
- แถบเล็กใต้ตัวอักษรแสดงอายุที่เหลือ

## ประตูมิติต่างโลก

- เวลาเรียงคำเริ่มต้น 60 วินาที ตั้งใน Home ได้ 15/30/45/60/90/120 วินาที
- แต่ละครั้งที่เข้าประตูเริ่มเวลาใหม่เต็มจำนวน
- ประตูแรกเกิดหลังเดินเกม 15 วินาที รอบถัดไปเว้น 30 วินาที อยู่บนสนามได้ 60 วินาที
- พิมพ์หรือเลือกตัวอักษรในกระเป๋า ตรวจจำนวนซ้ำจริง เช่น APPLE ต้องมี P สองตัว
- ส่งสำเร็จใช้ตัวอักษรนั้นออกจากกระเป๋า ได้คะแนนตามสูตร V1 และแสดงคำแปล
- มีช่วยเรียงคำ ลบ ล้างคำ พัก และกลับไปเก็บอักษรเพิ่ม
- หมดเวลาในรอบปกติหัก 100 คะแนน (ต่ำสุด 0) และลดหาง 1 ข้อ โดยไม่ต่ำกว่า 3 เก็บ inventory ไว้
- ห้ามส่งคำที่เคยตอบสำเร็จแล้วในรอบเดียวกัน (บทสอนไม่ตรวจ)
- Tutorial หมดเวลาแล้วเริ่มใหม่ได้โดยไม่เสียหัวใจหรือหาง
- ระดับคำเป็นป้ายข้อมูลจาก V1 บางส่วนยังไม่ได้ตรวจทานตามมาตรฐาน CEFR
- การค้นหาคำใช้ตัวสะกดตรงในคลังและไม่แยกตัวพิมพ์ใหญ่/เล็ก ยังไม่ได้ย้าย heuristics สำหรับเดาคำผัน/typo aliases ทุกกรณีจาก V1

## หัวใจและฟื้นคืนชีพ

ตามกติกาที่ผู้ใช้ยืนยัน:

1. เมื่องูชนขอบหรือชนตัวเอง ถ้าเหลือหัวใจ ให้แสดงโจทย์คำแปลไทย
2. ตอบคำอังกฤษให้ถูกภายใน 30 วินาที มีจำนวนตัวอักษรและอักษรแรกเป็นคำใบ้
3. ตอบผิดลองใหม่ได้ เวลาเดินต่อแต่ยังไม่หักหัวใจหรือคะแนน
4. ตอบถูกหักหัวใจ 1 ดวง และคะแนน 100 โดยคะแนนต่ำสุดเป็น 0
5. งูยาวเท่าเดิม (ไม่ลดขนาด) วางใหม่ในจุดปลอดภัย พร้อมนับถอยหลัง และสุ่มเสียตัวอักษรในกระเป๋า 5 ตัว (หรือเท่าที่มี) คำที่เรียนรู้ยังอยู่
6. รอบหนึ่งฟื้นได้สูงสุด 3 ครั้ง หลังใช้ครบแล้วตายอีกครั้งจะจบรอบ
7. หมดเวลาตอบหรือเลือกจบรอบ จะเข้าสรุปผล
8. โหมดฝึกสอนชนแล้วเริ่มจากจุดปลอดภัยได้โดยไม่หักหัวใจ

## กล่องตัวอักษร

ผู้ใช้เลือกเฉพาะเงิน ทอง ม่วง แดง จึงไม่มีกล่องเขียว

| กล่อง | รางวัล | โอกาสเกิดเริ่มต้น |
| --- | --- | --- |
| เงิน | 2 อักษร | 45% |
| ทอง | 3 อักษร | 30% |
| ม่วง | 4 อักษร | 18% |
| แดง | 5 อักษร | 7% |

ค่าโอกาสเกิดเป็นการปรับสมดุลเริ่มต้น แก้ได้ใน src/game/types.ts

- กล่องแรกเกิดหลังเวลาเดินเกม 7 วินาที จากนั้นเว้น 20 วินาที มีได้ครั้งละหนึ่งกล่อง
- กล่องที่ยังไม่เก็บอยู่ได้ 30 วินาที
- เดินเก็บแล้วโลกหยุด เปิดแผงสุ่มตัวอักษรประมาณ 1.6 วินาที
- กำหนดรางวัลครั้งเดียวตอนเก็บ การพักหรือ render ใหม่ไม่สุ่มซ้ำ
- กดรับแล้วเพิ่มอักษรให้ครบตามประเภท รับซ้ำไม่ได้
- ของจากกล่องเพิ่ม inventory โดยไม่เพิ่มหางทีละตัว
- โหมดลดการเคลื่อนไหวแสดงผลรางวัลทันที
- ระบบนี้เป็นของรางวัลจากการเล่น ไม่มีระบบซื้อกล่อง

## เวลา อินพุต และข้อมูล

- ใช้ simulation clock กลาง เวลาโลกไม่เดินระหว่าง challenge, chest, revive, result, lesson, pause และ countdown
- เวลาโจทย์/เปิดกล่องเดินเฉพาะสถานะนั้น และหยุดเมื่อ pause/สลับแท็บ
- กลับแท็บแล้วต้องกดเล่นต่อ งูจะเริ่มด้วย countdown; โจทย์กลับไปใช้เวลาที่เหลือ
- ขณะพิมพ์คำ ปุ่ม WASD/P เป็นตัวอักษรและไม่สั่งเลี้ยวงู
- ช่องเรียงคำรับเฉพาะอักษรที่มีในกระเป๋าตามจำนวนจริง ตรวจทั้งการพิมพ์ การวาง และการเลือกแทนที่ ถ้าวางเกินจำนวนจะคงคำเดิม กระเป๋าว่างจะอ่านได้อย่างเดียว
- กติกาแยกจาก Phaser; React รับ snapshot สำหรับ HUD และ modal
- ป้องกันกลับทิศเข้าตัวเองและจำกัดคิวเลี้ยว 2 คำสั่ง
- เซฟ settings, คะแนนสูงสุด, จำนวนรอบ และคำที่พบสูงสุด 500 คำในเบราว์เซอร์นั้น
- Tutorial ไม่เพิ่มคะแนนสูงสุดหรือจำนวนรอบปกติ

## กระเป๋า ประตูบังคับ และอิฐสีแดง

- กระเป๋ามีอักษรได้สูงสุด 30 ตัว อักษรที่เก็บเพิ่มตอนเต็มจะหายไปและมีข้อความแจ้ง รางวัลจากกล่องใส่ได้เท่าที่เหลือที่ว่าง
- เมื่อกระเป๋ามีอักษร 20–25 ตัว (สุ่มจุดเปิดต่อรอบการเติม) และไม่มีประตูบนสนาม เกมดึงผู้เล่นเข้าประตูทันที ไม่มีปุ่มออกจากประตูนั้น ถ้ามีประตูอยู่แล้วไม่บังคับ ระบบเปิดใช้ใหม่เมื่อกระเป๋าลดต่ำกว่า 20
- ทุกการเข้าประตูในรอบปกติมีช่วง "warp" 1.2 วินาที (0.6 วินาทีเมื่อลดการเคลื่อนไหว) หน้าจอสั่น มีเสียงเอฟเฟกต์ และโลกหยุดเวลา
- รอบปกติมีอิฐสีแดง 5 ก้อนบนสนาม ไม่เกิดใกล้หัวงูภายใน 8 ช่อง ชนแล้วอิฐแตก หัก 50 คะแนน (ต่ำสุด 0) และสุ่มเสียตัวอักษร 1 ตัว อิฐใหม่เกิดทดแทน แต่ถ้าคะแนนเป็น 0 อยู่แล้ว การชนอิฐนับเป็นการตาย (เข้าฟื้นคืนชีพหรือจบรอบตามหัวใจ) บทสอนไม่มีกติกานี้
- อิฐอยู่ได้ 40 วินาทีของเวลาเล่นจริง ตัวอักษรและอิฐแสดงเวลาที่เหลือด้วยสีที่ค่อย ๆ จางจากด้านบนลงล่าง (ไม่มีหลอดเวลา) และกะพริบเมื่อเหลือต่ำกว่า 20%
- บทสอนอิฐมีอิฐเดียวที่ไม่หมดอายุ และให้ C A T ในกระเป๋าไว้ดูผลหลังชน
